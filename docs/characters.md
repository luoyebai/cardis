# 角色与组别

`assets/characters.json` 是角色资料和开局阵容的唯一来源；`assets/cards.json` 保存技能和可上场角色卡。
当前 P1 为后藤一里，P2 为千早爱音。角色页的“P1 角色 / P2 角色”可切换查看，持有优先权的玩家使用自己的技能手牌。
点击“资料与技能”可查看完整资料。切换资料页不会改变对局阵容。

## 字段

| 字段 | 用途 |
|---|---|
| id / name / original_name | 稳定 ID、显示名、原文名 |
| group_id | 所属组别，引用 groups 中的 ID；组别有名称和类别 |
| gender | female / male / non_binary / unspecified，界面本地化显示 |
| origin / species / occupation | 原作品、种族、身份 |
| biography / source_url | 简介与资料来源 |
| title / tags | 称号与角色标签；不暗含未实现的被动效果 |
| portrait / artist / license | 立绘及资源来源信息 |
| gameplay.role | Cardis 战斗定位 |
| gameplay.starting_life | 初始生命，整数 1–100，实际用于开局和重开 |
| gameplay.max_mana | 灵力最终上限，整数 1–10；当前上限从 0 开始，己方回合增加 1 |
| gameplay.skill_ids | 角色专属技能列表，引用 cards 且必须属于该角色；初始手牌从牌库随机抽取 |

顶层 `players` 恰好两个角色 ID，分别对应 P1 / P2。修改后重新启动。
专属卡设置 `character_id`；通用卡可省略。卡面图片从对应角色资料读取，通用卡使用文字占位。
同一组别目前是资料与未来协同规则的分类，不会自动产生组队加成；性别也不影响数值。
没有添加尚未运行的隐藏被动或伪数值。

这些技能是 Cardis 自定义玩法，不是原作品官方技能。玩家治疗不超过 starting_life，单位治疗不超过卡牌 health。
每个技能在起始牌组中有两张；每位玩家的 3 种专属技能、1 种作品角色牌及 11 种通用牌构成 30 张牌库。
后藤一里角色牌为 4 费 4/4，千早爱音为 3 费 2/5 守护。角色资料展示与实际召唤入场是不同概念。
护盾持续到被消耗；单位受伤跨回合保留。角色详情展示三个专属技能。

## 校验和扩展

加载时校验重复 ID、未知组别、非法性别、超范围数值、非整数数值、无效路径、未知/重复/跨角色技能、无法支付的技能及无效阵容。
`Game` 仍只依赖标准库，JSON 在内容层解析。重开保留阵容和角色初始属性。
新增文字后运行 `tools/update_glyphs.ps1`，再构建以同步资源。
